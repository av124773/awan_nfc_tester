# AWAN NFC 產品測試系統 — 操作說明書

本系統用於產線 NFC 標籤的自動化檢測，包含條碼格式確認、NFC 資料寫入與讀取比對，並自動產生生產紀錄。

## 1. 準備工作

在開始安裝前，請確認您的設備具備以下條件：
* **硬體**：已連接 NXP NCI 相容的 NFC 感應模組。
* **設備**：建議使用安裝了 Linux 系統的電腦或 Raspberry Pi。
* **工具**：一支可用的條碼掃描槍。

## 2. 系統安裝 (僅需執行一次)

請依照以下順序在終端機輸入指令。如果您不熟悉指令，請直接複製並貼上：

### 第一步：安裝感應器驅動程式
```bash
cd vendor/linux_libnfc-nci
./bootstrap
./configure
make
sudo make install
```

### 第二步：編譯測試工具
```bash
# 返回主目錄並執行編譯腳本
chmod +x scripts/build.sh
./scripts/build.sh
```

### 第三步：準備運行環境
```bash
# 建立並啟動環境 (venv)
python -m venv venv
source venv/bin/activate

# 安裝必要的軟體包
pip install -r backend/requirements.txt
```

## 3. 如何啟動系統

每次重新開機後，請執行以下腳本來開啟測試介面：

```bash
# 使用專屬啟動腳本
chmod +x backend/run_server.sh
./backend/run_server.sh
```
啟動成功後，請開啟瀏覽器並輸入網址：`http://localhost:8000`

## 4. 每日生產操作流程

### 步驟 A：設定工單
1. 在網頁首頁輸入當前的**工單號碼**。
2. 輸入或掃描**範本條碼**（這將作為後續所有產品條碼的格式標準）。
3. 填寫其他必要欄位（如作業員編號）後，點擊「開始測試」。

### 步驟 B：執行檢測
1. **放置產品**：將待測產品放置在 NFC 感應區。
2. **掃描條碼**：使用掃描槍讀取產品條碼。
3. **自動判定**：
   * **綠色畫面 (PASS)**：表示寫入與讀取完全正確，系統已紀錄 UID。
   * **紅色畫面 (FAIL)**：表示測試失敗。請根據螢幕提示（如「感應超時」或「資料不符」）進行排除。
4. **重複預防**：若掃描到已經測過 PASS 的條碼，系統會彈出警告，防止重複生產紀錄。

### 步驟 C：下載紀錄
測試結束或下班前，點擊網頁上的「下載 CSV」按鈕，即可取得該批次的完整測試報告。

## 5. 常見問題排除

* **網頁無法連線**：請確認是否有執行 `run_server.sh` 啟動伺服器。
* **條碼錯誤 (FORMAT_ERROR)**：請檢查產品條碼是否為 21 碼，且前 14 碼必須與範本完全相同。
* **讀寫工具繁忙 (BUSY)**：若系統卡住，請重整網頁。後端會自動清理未正常關閉的底層工具。
* **流水號格式不符**：請確認條碼中間的流水號是否包含 `0-9` 與 `A-V` 以外的字元。
